# Verify the host, setting and running window

Select **Check again** after reloading. Output shows the host prerequisites, effective Runtime Persistence setting and whether this window has applied it. The sidebar also shows the latest state.

## What “ready” means

Setup is verified only when the host prerequisites pass, the setting is enabled and this window has applied it. Each Supervisor service is still verified before a new session starts. Checking does not restart existing executions.

If a window reload is required, review its warning before continuing: changing persistence mode can clear Canvas content and sessions.

## Progress is not live status

Walkthrough checkmarks record guide progress and may remain checked on another host. They do not prove that linger is enabled. Recheck after reconnecting or changing system settings.
