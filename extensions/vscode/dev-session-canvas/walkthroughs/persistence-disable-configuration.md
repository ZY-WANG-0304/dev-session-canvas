# Turn off the effective setting

Opening this guide automatically reads the effective setting and this window’s applied mode; no system eligibility check is required. It selects the next unfinished task without a separate check step.

When applied, this window leaves the shared Canvas without retaining its sessions or content. Other participating windows keep shared sessions; the last enabled window explicitly turning off clears shared sessions and content and exits the Supervisor. Participation is checked during the existing protected shutdown flow. Save your work before applying the change.

Select **Open setting**, choose the intended User, Remote or Workspace scope, and uncheck **Runtime Persistence: Enabled**. Workspace values can override user values; the guide checks the effective value rather than assuming a scope.

Wait for Settings to save, return to this guide and select **continue**. The extension does not write settings on your behalf.

A saved `false` value is only a request. If this window still runs in persistent mode, the next step offers a reload after explaining the impact.

To undo a pending turn-off request, recheck the setting before reloading. Turning off this extension setting does not revoke system linger.
