# 这是一项账号级变更

打开引导会自动检查主机与账号。环境就绪时，本步骤保留并打钩，自动进入下一待办，无需先点击检查。检查失败时，请查看输出面板，并用**重新检查 / 查看详情**重试；检查失败不代表允许执行命令。

Linger 是**系统设置**，不是 VS Code 偏好。此账号的其他用户服务也可能在退出登录后继续运行。

## 由你决定是否执行

- 确认时展示实际主机、账号和完整命令。
- 默认命令**不使用 sudo**。
- 如需管理员授权，单独选择**使用 sudo…**。密码只在专用终端中输入，扩展不收集密码。
- 复制命令不会执行它。

关闭 Runtime Persistence 或卸载扩展，不会关闭 linger。Linger 不能在主机重启后保留原进程。
