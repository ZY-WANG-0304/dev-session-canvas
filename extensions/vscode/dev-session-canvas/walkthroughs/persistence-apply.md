# Apply the requested mode

Changing the setting does not switch the running window immediately. A window reload is required.

## Finish or save your work first

Switching modes clears this window’s Canvas sessions and content. Select **Review and reload…**, read the warning, and confirm only when you are ready. Cancelling leaves the current window running in its existing mode.

The action checks the host and setting again before offering reload. If a prerequisite is missing, the guide returns to that step instead.

After reloading, return to **Verify the result** and select **Check again**. A saved setting alone does not complete setup.
