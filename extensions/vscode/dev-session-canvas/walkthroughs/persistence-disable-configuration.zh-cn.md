# 关闭实际生效的配置

打开引导会自动读取有效设置与当前窗口实际模式，不要求系统资格正常；无需单独的检查步骤，直接定位下一待办。

应用时，当前窗口退出共享画板，不保留其中的会话与内容。其他参与窗口继续保留共享会话；最后一个启用窗口明确关闭时，才清空共享会话与内容并退出 Supervisor。参与关系由现有受保护的退出流程判断。请在应用前保存工作。

点击**打开配置项**，选择需要的用户、远程或工作区作用域，取消勾选 **Runtime Persistence: Enabled**。工作区值可能覆盖用户值；引导会检查实际生效的配置，而不是假定作用域。

等待设置保存后，回到此引导点击**继续检查**。扩展不会代替用户写入设置。

保存 `false` 只是关闭请求。如果当前窗口仍运行在持久模式，下一步会说明影响并提供重载入口。

若要撤销尚未应用的关闭请求，请在重载前重新勾选配置。关闭这个扩展配置不会撤销系统 linger。
