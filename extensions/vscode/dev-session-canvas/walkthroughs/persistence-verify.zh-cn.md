# 同时确认主机、配置与当前窗口

重载后点击**重新检查**。输出面板分别显示主机前提、实际生效的 Runtime Persistence 配置，以及当前窗口是否已应用；侧栏也保留最近一次状态。

## “已就绪”代表什么

只有主机前提通过、配置已开启且当前窗口已应用，才表示配置验证通过。新建会话前仍会验证各个 Supervisor 服务的托管条件；检查不会重启已有执行。

如果提示需要重载窗口，请先阅读警告：切换持久运行模式可能清空画板内容和会话。

## 引导进度不是实时状态

引导页的勾选记录阅读进度，在其他主机上也可能保留，不代表 linger 已开启。重新连接或修改系统设置后，请重新检查。
