# Verify the window, not just the checkbox

After reloading, select **Check again**. Both the effective setting and this window’s applied mode must be off. Output reports each separately; saved guide checkmarks are not live status.

This confirms only this window. Other participating windows, workspaces and account services may still be running.

## Optional system rollback

Linger is account-wide and is **not automatically disabled**. Keeping it enabled is valid after turning off this extension’s persistence.

If you also want to revoke linger, select **review system linger rollback** after this window is off. This only displays the latest system check and, when the target is verified, exact manual commands in Output. Nothing is executed. Review other services with your administrator first; the extension cannot prove they no longer depend on linger. After any manual change, use the same review link to check again.
