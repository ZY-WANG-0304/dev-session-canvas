# 画布关系连线规格

当前状态：通用手工连线继续支持；Agent 自动文件活动、文件节点、文件列表、活动边及对应设置已按 2026-11-01 决策退役。退役范围与旧画布迁移口径见[画布文件活动功能退役设计](../design-docs/canvas-file-activity-retirement.md)，实施和验收证据见[执行计划](../exec-plans/completed/canvas-remove-file-nodes.md)。本文只约束仍然存在的通用连线行为；同名旧设计文档中有关自动边的历史描述已由退役设计取代。

## 用户目标

- 用户可以在当前画布节点之间手工创建关系连线，表达不附带预设含义的对象关系。
- 连线与画布状态一起持久化，重载后保持。
- 连线可以被选择、编辑、重接和删除；删除节点时清除连接到该节点的边。
- 多根组合画布只允许在同一 root 内创建或重接连线，避免生成无法保存回单 root 的关系。

## 行为约束

- 连线端点引用当前存在的节点；端点锚点为上、右、下、左之一。
- 连线支持箭头模式、颜色和标签。没有标签时不显示占位文案。
- 用户编辑与删除只作用于手工连线；重载不通过 Agent 输出或文件访问活动重建连线。
- 连线由宿主持久化的画布状态拥有，Webview 负责交互和呈现，不能把本地 edge 状态当作权威事实。
- `file` / `file-list` 节点不属于当前节点模型。旧状态中的这些节点及其关联边由退役迁移规则清理。

## 验收

- 创建手工连线后，编辑标签、箭头、颜色和端点并重载，结果保持一致。
- 删除手工连线只删除该连线；删除节点后，不留下引用该节点的关系边。
- 在多根组合视图中尝试跨 root 连线或重接时不产生或持久化该边。
- 旧画布迁移后，普通连线保留，指向已删除旧文件节点的边被清理。

历史决策与早期实现细节保留在版本历史和旧设计记录中，不再作为当前文件活动功能承诺。
