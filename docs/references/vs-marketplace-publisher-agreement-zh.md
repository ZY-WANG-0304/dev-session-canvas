# Microsoft Visual Studio Marketplace 发布者协议（中文译本）

> 原文生效日期：2021年6月

感谢您有意在 Microsoft Visual Studio Marketplace 中发布产品。本协议（"协议"）规定了您与 Microsoft Corporation（"Microsoft"）之间的关系，并约束您在 Marketplace 中的产品列表行为。

点击接受、提交产品发布申请，或访问发布者账户相关功能，即表示您同意本协议条款。Microsoft 可随时更新本协议，并在文档顶部注明变更时间。

---

## 第1条 定义

- **关联公司**：拥有、被拥有或与某方共同拥有的法律实体（所有权超过50%）。
- **发布者账户**：用于通过 Marketplace 发布产品的账户，至少包含用户名和密码。
- **发布门户**：可通过 https://marketplace.visualstudio.com/manage 访问的网页门户。
- **Marketplace**：Microsoft 策划的有限资源库，用于发布供 In-Scope 产品和服务使用的产品链接。
- **Marketplace 参与政策**：发布 Marketplace 产品的业务政策和要求，详见 http://aka.ms/vsmarketplace-policies。
- **产品**：在 Marketplace 中发布或拟发布的任何软件、数据、媒体或服务。
- **产品资产**：产品名称、商标、徽标、图标、描述、截图、视频等元数据。
- **列表信息**：随产品一起提供的说明信息，包括性质、费用、使用条款等。
- **机密信息**：一方指定为机密或在披露情况下应视为机密的所有非公开信息。
- **个人数据**：与已识别或可识别的自然人相关的任何信息。

---

## 第2条 发布者账户

提交产品须通过发布门户开立发布者账户并提供 Microsoft 所需的所有信息。您对发布者账户下发生的所有活动负责。若账户未能保持良好状态，Microsoft 可撤销账户、从 Marketplace 移除产品，并追究其他相应责任。

---

## 第3条 产品的提交、审批与分发

**(a) In-Scope 产品和服务**：产品必须为 Visual Studio、Visual Studio Code、GitHub Codespaces、Azure DevOps 等产品及其后继服务设计。

**(b) Microsoft 的代理身份**：Microsoft 作为您的代理提供 Marketplace 技术和服务，但您（而非 Microsoft）是产品的分发商。

**(c) 提交**：您须向 Microsoft 提交每个希望在 Marketplace 上架的产品及其资产和更新。Microsoft 没有义务上架您提交的产品。您对产品、产品资产和列表信息承担全部责任。

**(d) 产品更新**：更新提交须满足本协议的所有要求。

**(e) 发布后保证**：产品发布后，Microsoft 可定期测试和评估，以验证是否持续符合协议要求。

**(f) 移除产品**：
- 您可通过发布者账户移除产品（付费产品须提前30天通知）。
- 移除仅影响新用户，现有用户可继续使用。

**(g) Microsoft 的移除和禁用权**：Microsoft 可出于任何原因随时移除或暂停任何产品，包括：
1. 您违反协议条款（含 Marketplace 参与政策）
2. 产品与列表信息不一致
3. 侵犯第三方知识产权
4. 用户投诉产品内容或质量
5. 未能为用户或 Microsoft 提供足够支持
6. 违反任何适用法律法规

若产品对用户、设备或网络造成危害，Microsoft 也可禁用产品。

**(h) 侵权投诉**：如认为其他产品侵犯您的权利，可按 Microsoft 的通知和下架流程提交投诉。

**(i) 产品呈现**：Microsoft 对 Marketplace 中产品的展示位置和推广拥有最终决定权。

**(j) 排名和评分**：您不得试图操纵任何产品的排名、评分或评论。

---

## 第4条 产品许可与支持

**(a) 您授予的权利**：提交产品即授予 Microsoft 全球范围内非独家的托管、使用、复制、展示、分发等权利，以及展示您的商标标志的许可。

**(b) 第三方权利/开源许可**：产品不得侵犯任何第三方的知识产权。若使用第三方或开源代码，您须独立承担合规责任。

**(c) 向用户许可**：由您（而非 Microsoft）向用户授予产品使用权。您可提供自己的最终用户许可协议，或选用 Microsoft 标准协议。

**(d) Microsoft 商标许可**：产品上架期间，Microsoft 授予您非独家、不可转让的有限商标使用许可，仅用于按 Microsoft 品牌指南宣传您的产品。

---

## 第5条 在 GitHub Codespaces 中使用您的产品

您授予 GitHub、Microsoft 及第三方运营商存储、托管、捆绑和推荐您产品的权利，以便用户在 Codespaces 中使用。

---

## 第6条 产品要求

**(a) 一般要求**：产品须符合本协议、Marketplace 参与政策及相关文档。

**(b) 当地法律**：产品及其营销须遵守您选择发布的每个国家或地区的适用法律，包括数据保护法、电信法、消费者保护法、出口管制法等。

**(c) 支持**：对于付费且正式发布（非预览版）的产品，您须为用户提供支持服务。

---

## 第7条 费用、付款与税务

- 您独自负责向用户提供定价信息并在 Marketplace 之外完成收费。
- 您独自承担退款、退单、税务等相关费用和义务。

---

## 第8条 保密、隐私、安全与数据保护

**(a) 保密**：双方在协议期间及之后5年内对机密信息保密。

**(b) 隐私**：若产品访问或收集个人数据，须维护并向用户公示隐私政策。

**(c) 数据保护**：双方须遵守所有适用的数据保护法律。

**(d) 安全**：
- 您的产品、网络和系统须采取合理的安全措施保护用户信息。
- **产品不得危害用户安全**，不得安装或启动超出列表信息说明的可执行代码。
- 须尽早报告安全事件和漏洞。

---

## 第9条 报告

Microsoft 将在适用税法要求范围内提供报告功能，包括产品下载量的汇总信息。

---

## 第10条 保证

您向 Microsoft 声明并保证：
- 您有权签署并履行本协议。
- 您的产品和产品资产符合协议要求，并将持续符合。
- 您的产品上架和分发不违反您所参与的任何协议。
- 您向 Microsoft 提供的信息真实、准确、完整。
- 您遵守所有适用法律，包括隐私法。

---

## 第11条 免责声明、责任限制与索赔防御

**(a) 免责声明**：Microsoft 按"现状"和"可用"方式提供发布门户和 Marketplace，不提供任何明示或默示担保。

**(b) 责任限制**：Microsoft 的最高赔偿责任上限为 **5,000 美元**，不承担任何间接、惩罚性或附带损害赔偿责任。

**(c) 赔偿**：您须为涉及您产品的第三方索赔提供辩护、赔偿并使 Microsoft 免受损害，包括知识产权侵权、违约、产品责任等索赔。

**(d) 索赔期限**：与本协议相关的任何索赔须在知情后一年内提出，否则永久丧失索赔权。

---

## 第12条 期限与终止

**(a) 便利终止**：Microsoft 可在提前30天书面通知后随时终止协议；您可通过移除所有产品并关闭账户来终止协议。

**(b) 终止效力**：终止通知后30天内，Microsoft 将移除您的所有产品。Microsoft 可酌情加速移除。

**(c) 单个产品终止**：Microsoft 可就某一特定产品终止本协议，而不影响其他产品。

**(d) 服务产品过渡期**：服务类产品从 Marketplace 移除后，现有用户可继续使用90天或订阅到期（以较长者为准）。

---

## 第13条 贸易法律合规

双方须遵守美国及其他国家/地区的出口管制和制裁法律法规。如 Microsoft 认为履约可能违反贸易法律，可立即暂停或终止本协议。

---

## 第14条 其他条款

- **通知**：您向 Microsoft 发送的通知须发送至 vsmarketplace@microsoft.com 和 vsmagent@microsoft.com。
- **准据法**：本协议适用华盛顿州法律，争议在华盛顿州金县法院解决。
- **整体协议**：本协议构成双方就 Marketplace 产品事宜的完整协议。

---

## 附件 A：产品类型

**第1条** Azure DevOps 扩展：为 Azure DevOps 账户提供新功能的扩展，只能与 Azure DevOps 及其后继服务配合使用。

**第2条** Visual Studio / VS Code / GitHub Codespaces 扩展：安装到 VS、VS Code、VS for Mac 或 Codespaces 实例中的扩展，只能与上述产品配合使用。

**第3条** 集成和仅目录列表：不直接通过 Marketplace 提供，而是提供链接和说明引导用户前往您的网站获取的产品。

**第4条** 服务类产品：从 Marketplace 移除后，须继续为现有用户提供服务90天或至订阅到期。
