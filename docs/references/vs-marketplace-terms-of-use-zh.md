# Microsoft Visual Studio Marketplace 使用条款（中文译本）

> 最后更新：2025年9月

---

## 1. 简介

Microsoft Visual Studio Marketplace（"Marketplace"）和 NuGet.org（"NuGet"）均受以下使用条款（"协议"）的约束。两个网站统称为"网站"，均由 Microsoft Corporation 托管（地址：One Microsoft Way, Redmond, WA 98052, U.S.）。

访问或使用任一网站，即表示您同意受本协议约束。

Marketplace 为您提供访问或购买产品和服务（"Marketplace 产品"）的渠道，这些产品旨在与 Visual Studio、Visual Studio Code、GitHub Codespaces、Azure DevOps 等 Microsoft 产品配合使用。

## 2. 使用条件：Marketplace 使用权

**(a) 发布者使用条款**：使用任何发布者产品的权利由发布者提供的单独使用条款约束。Microsoft 不是发布者使用条款的当事方，您与发布者之间的交易由您自行负责。

**(b) Marketplace 产品**：您使用 Marketplace 产品的权利受您购买/获取该产品时所依据的协议约束，Marketplace 产品仅供与 In-Scope 产品和服务配合使用。

**(c) BYOL 产品**：若您使用"自带许可（BYOL）"产品，您须确保自己拥有足够的使用权利。

**(d) 发布者政策**：发布者受其与 Microsoft 之间的发布者协议约束。发布者独自负责遵守所有适用法律。

**(e) API**：如使用 Marketplace API 购买或访问产品，您须遵守界面中呈现的适用使用条款。

## 3. 使用条件：Marketplace/NuGet 产品使用权

您不得将网站用于任何违法或违反本协议的目的，包括但不限于：

- 损害、禁用、超负荷或损害任何 Microsoft 服务器或网络

- 在 In-Scope 产品和服务之外安装、使用 Microsoft 或 GitHub 发布的产品
