# Microsoft Visual Studio Marketplace 参与政策（中文译本）

> 来源：`Visual-Studio-Marketplace-Participation-Policies.pdf`
>
> 原文最后更新：2021年6月
>
> 说明：本文为非官方中文翻译，仅用于阅读和合规梳理；如与英文原文存在歧义或冲突，应以英文原文为准。为便于阅读，本文将 “Offering” 译为“产品”，将 “Publisher” 译为“发布者”，将 “In-Scope Products and Services” 译为“范围内产品和服务”。

---

这些 Microsoft Visual Studio Marketplace 参与政策（下称“本政策”）适用于 Visual Studio Marketplace 中的所有发布者和产品。本政策是对《Microsoft Visual Studio Marketplace 发布者协议》（下称“发布者协议”）所列条款和条件的补充。

发布者如要参与 Visual Studio Marketplace，必须始终遵守本政策中描述和/或引用的政策。如果发布者在任何时候未能满足所有条款和条件，Microsoft 可采取包括从 Visual Studio Marketplace 移除该发布者产品在内的措施。

Microsoft 可随时更新本政策。在变更生效后继续使用发布者账户或继续在 Marketplace 中列出产品，即构成对新条款的同意。如果发布者不同意新条款，则必须从 Marketplace 移除其产品并关闭其发布者账户。

本政策中未定义的所有首字母大写术语，均应具有发布者协议正文中赋予的含义。

---

## 第1条 基本标准

**(a)** 产品必须设计为能够与 Microsoft Visual Studio、Visual Studio for Mac、Visual Studio Code、GitHub Codespaces、Azure DevOps、Azure DevOps Server，以及 Microsoft 和 GitHub 提供的后续产品和服务（合称“范围内产品和服务”）配合使用并扩展其能力。产品仅供与范围内产品和服务配合使用，并且只能随范围内产品和服务安装和使用。

**(b)** 发布者不得开发或允许他人开发任何会规避范围内产品和服务中所实施技术限制的产品。

**(c)** 发布者应设计并测试其产品的下载、安装和卸载流程，以确保这些流程不会禁用范围内产品和服务的任何功能，也不会对范围内产品和服务的功能产生不利影响。

**(d)** 发布者不得主动发起任何会显示在范围内产品和服务中的通知，除非该通知：

1. 明确标识为来自发布者自身，而非来自 Microsoft；并且
2. 在其他方面符合发布者协议，包括本政策。

**(e)** 发布者不得禁用或以其他方式更改范围内产品和服务中由 Microsoft 管理的任何设置，也不得允许用户禁用或以其他方式更改这些设置；这里的设置包括 Microsoft 在相关范围内产品和服务中允许用户管理的设置。

**(f)** 付费产品的发布者必须位于 Azure Marketplace 支持的地理位置内。支持的地理位置列表请参见[此处](https://docs.microsoft.com/en-us/azure/marketplace/marketplace-geo-availability-currencies)。

**(g)** 付费产品的发布者必须保持良好的财务信誉状态。

**(h)** Marketplace 中的产品不得使用或依赖任何不受支持或已不再商业供应的产品或组件。

**(i)** 发布者必须提供详细的技术文档。该文档需要说明如何将其产品与范围内产品和服务配合使用。每个产品都必须在其列表信息中提供或链接至此类文档。

---

## 第2条 发布产品

发布者必须在签署发布者协议后 60 天内，在 Marketplace 中发布至少一个产品。付费产品的发布者必须遵守本政策中描述的 Visual Studio Marketplace 入驻技术要求，以及发布门户中可能进一步说明的要求。

---

## 第3条 产品列表信息

**(a)** 发布者必须在其产品的列表信息中包含详细的产品信息，并确保这些信息准确且保持最新。此类信息可包括以下适用内容：

### (i) 产品描述

#### (1) 最低产品描述要求

- SKU 信息；以及
- 价值主张。

#### (2) 推荐产品描述内容

- 详细的 SKU 信息；
- 详细的价值主张；
- 功能：关于该产品的 3 至 5 条事实性陈述；
- 收益：由该产品功能产生的 3 至 5 项结果。

#### (3) 定价模式

- 产品必须兼容本文第4条中描述的定价模式。

#### (4) 客户支持详情链接

- 对于 Visual Studio Marketplace 中的付费且已完全可用（即非预览版本）产品，发布者必须提供商业上合理的客户支持。该支持可以包含在与该产品相关的费用中，也可以作为单独购买的支持产品提供。

#### (5) 产品资源

- 资源包括但不限于演示视频、截图、白皮书、案例研究、客户证言，以及关于如何将发布者产品与范围内产品和服务配合使用的详细技术文档。

#### (6) 使用条款

除非选择了 Microsoft 标准合同，或该产品为 BYOL 产品，否则应提供使用条款。

#### (7) 隐私政策

应提供隐私政策。

**(b)** 发布者不得在以下任何位置宣传其其他产品在竞争性云平台上的可用性，也不得宣传其与竞争性集成开发环境（IDE）或编辑器相关的其他产品：

1. Visual Studio Marketplace；
2. 范围内产品和服务；或
3. 发布者的产品中，包括下载或安装体验中。

**(c)** Microsoft 保留出于质量保证目的编辑和修订产品列表页面详情的权利。如果 Microsoft 对任何列表页面详情作出任何更改，Microsoft 将在该产品列表页面发布到 Visual Studio Marketplace 之前告知发布者。

## 第4条 付费产品的定价模式

Visual Studio Marketplace 支持发布门户中呈现的定价模式。下表说明 Marketplace 当前支持的定价模式。

| 定价模式 | 描述 |
| --- | --- |
| 免费 | 免费 SKU。客户使用该产品不会被收取费用。免费 SKU 的价格不得提高至非零金额。 |
| 免费试用（Try it now） | 限时促销免费 SKU。客户在试用期内通过 Marketplace 使用该产品不会被收取费用；试用期结束后，发布者负责在 Marketplace 之外设置计费并收取用户费用。Marketplace 目前无法阻止客户为免费试用产品创建多个订阅。希望限制客户可为免费试用产品创建订阅数量的发布者，负责在其使用条款中加入适当限制。 |
| 付费 / BYOL | 自带许可（Bring-Your-Own-License，BYOL）SKU。如果客户已在 Visual Studio Marketplace 之外取得该产品的访问权或使用权，则 Marketplace 不会向客户收取费用。 |

---

## 第5条 产品暂停和移除

**(a)** Microsoft 保留以任何理由从 Visual Studio Marketplace 暂停或移除产品的权利。Microsoft 可能移除产品的原因包括但不限于：

1. 该产品在六个月或更长时间内未被任何客户预配；
2. 该产品持续收到负面客户反馈；
3. 该产品持续收到大量支持工单；或
4. 发布者未能遵守《Microsoft Visual Studio Marketplace 发布者协议》或本政策中的条款和条件。

**(b)** 希望移除付费 Azure DevOps 产品的发布者，应发送电子邮件至 `vsmarketplace@microsoft.com`。

---

## 第6条 安全事件

发布者必须尽早报告疑似安全事件，包括其 Marketplace 产品的安全事故和漏洞。
