# v0.26.1 发布契约

## 发布范围

主扩展与 notifier 同步为 0.26.1，交付 0.26.0 之后已合入主线的执行可靠性和同 root 共享画布。范围包括 root 稳定归属、启动失败反馈与准入收口、旧历史清理/协议重连、本地 Agent/Terminal 生命周期、终端输入/resize/拖放/文件链接/文件活动、恢复身份和执行提醒，以及持久化模式切换的共享清理与接管。

保持公开 Preview、现有设置、扩展身份和安装关系。notifier 自身不增加投递后端、协议、点击回跳或语言行为。模板市场生产部署独立于插件发布；多设备、多用户与云同步不在范围内。

## 用户 release notes

开启 Runtime Persistence 时，同执行环境、用户存储范围和 root 的画布结构在多个窗口同步；共享删除移除各窗口节点投影，stop 保留节点和退出状态。关闭模式按工作区私有保存。修改开关在关闭或重载边界应用，不迁移私有/共享内容；非最后开启窗口切换关闭仅退出自己的共享模式，最后一个才启动共享清理，新开启窗口可以按清理阶段接管。未切换模式的普通关闭或重载继续保留共享会话。

启动失败显示底层原因、清除待启动态并保留安全重试/删除；修复启动期间尺寸协调、删除前输入收口、本地执行终态/保存/重载、路径拖放、逐行和换行文件链接、文件活动及提醒。snapshot-only 下因 Host 关闭中断、有可信恢复身份的 Agent 等待手动 Resume，重开页面不自动恢复。

升级前停止重要会话、另行保存需要留存的输出并备份画布，主扩展与 notifier 建议一起升级。已结束持久化 Runtime 仍不恢复终端正文或自动执行；provider 自身会话文件与显式 Resume 独立保留。旧 live 会话不自动迁移到新协议；跨版本回退需要重新验证，优先后续 0.26.x 修复版。

## 已知限制

Supervisor 崩溃、执行机器重启或断电后不保证原进程和终端历史恢复。资源随会话数、尺寸和 scrollback 增长，无固定总内存/磁盘配额或零延迟承诺。旧 live 协议不获得新完整性保证，跨版本工作区/运行时数据回退不保证兼容；共享/私有模式切换会舍弃原模式内容，应事先备份。

部分 VS Code 版本在连续快速重开时可能积压已关闭 Webview 的资源请求，延迟新画布加载。持续启动失败可能留下空白画布，当前没有专门的启动超时提示、自动重试或重建；较长测试等待不提供上述产品能力。

原生资产覆盖 Linux glibc、macOS、Windows x64/arm64，现代系统证据不外推旧系统或 Linux musl。Windows Codex 历史向上翻页限制保留；Restricted Mode 执行入口禁用，Virtual Workspace 不支持。共享画布真实 UI 证据限 Linux 单 root；四阶段接管有受控 Host/store 和独立 Supervisor 证据，不等同全平台、多 root 或 Remote SSH 接管 UI 验收。notifier 投递和点击回跳依赖本机权限与后端。

## 验证范围

本版使用标准完整 release:verify，不继承 0.26.0 的一次性验证例外。验证覆盖发布脚本/契约回归、完整 npm test 和干净源码的独立依赖安装、VSIX 打包及全部八场景安装 smoke；PR 最新 head 预合并结果与正式发布 tag 各自执行。

重点核对启动/准入失败呈现、原执行终态和保存、删除前输入关闭、resize 后页面与原进程尺寸一致、旧会话重连和退役、真实新 Host/checkpoint、同 root 双窗口结构同步/切换、systemd 与 fallback 及 localhost SSH。Webview 全套保持原断言和截图基线；fake Agent 与 Linux 本机结果不代证真实 provider 或其他平台组合。

另复核 notifier 类型/build/source、companion 回跳、英中文 locale 和独立 VSIX 的版本、README、安装依赖及 NLS/l10n。真实桌面点击与公开市场自动补齐按实际宿主/渠道检查，staged smoke 不代证系统权限或市场依赖安装。
