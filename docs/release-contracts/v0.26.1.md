# v0.26.1 发布契约

## 发布范围

本版收口 `0.26.0` 之后已合入 main 的运行时修复，主扩展与 notifier 统一为 `0.26.1`，保持公开 Preview。包含按 root 稳定的新增持久会话归属、启动拒绝原因与责任结算、Supervisor 请求等待上限、无代次旧历史清理，关闭运行时持久化时的输出提醒桥接，以及终端文件链接折行与悬停显示修复。

notifier 包自身仅版本对齐，提醒修复位于主扩展；不新增通知协议、后端、用户设置、安装依赖或模板市场生产服务部署。保留 0.26 的当前状态重新附着、退出完整性与已结束 Runtime 轻量保存语义。

## 用户 release notes

新建持久化 Agent / Terminal 会话按工程目录（workspace folder/root）确定运行时归属。同一执行环境、用户存储范围、root 与兼容代共享归属，单根、多根、Pane Gallery 和创建窗口不改变它；不同 root 分开托管。已有 live 会话继续按原 backend、storage 与 session 绑定连接，不自动迁移，也不自动跟随目录移动。

启动失败显示底层原因；确认本次创建未获取资源且已完成清理时，节点退出 Starting / Resuming，恢复重试和删除。普通握手与请求无响应时明确返回超时，结果仍可能未知、操作可能已经发生，不自动重发；迟到的终端读取资源继续承担清理责任。旧版无代次存储的纯历史节点在满足清理证据时可以删除，未知状态仍保守保护。

关闭运行时持久化时，Agent / Terminal 输出中的提醒信号重新按原设置通知节点、notifier 或工作台；确认提醒后继续输出与保存正常衔接。两扩展应同时升级，桌面投递与点击回跳仍依赖本机权限和后端。

修复窄终端中带样式文件路径跨软折行与硬换行时的链接识别，保留行列号；路径满行后右括号或说明换到下一行时仍可完整点击，选区重绘后悬停下划线继续显示。

升级前停止重要会话、另存输出并备份画布。已结束持久会话重开仍不恢复终端正文或自动 start/resume；snapshot-only、provider 会话文件和显式 Resume 独立保留。回退前停止新会话，旧版不保证识别新归属元数据或跨版本运行时数据，优先后续修复版。

## 已知限制

终端文件路径的混合折行识别依赖可验证的同样式片段，最多四个物理行；不自动拼接任意无样式多行文本。

共享 runtime owner 不提供通用的多窗口画布编辑/保存事务。同 root 的归属受执行环境、用户存储范围和兼容代约束，不跨机器托管；身份未知或不安全时拒绝新建。多个 root 分别托管增加进程开销，不承诺任意 root 数、会话数或固定总内存/磁盘预算。

Supervisor 崩溃、机器重启或断电后不保证进程或终端历史恢复。旧 live 不升级协议，不因新超时或拒绝结算规则把历史未知责任追认为可清理。普通请求预算不是远端执行或后端启动的耗时保证。

平台支持沿用现代 Linux glibc、macOS、Windows x64/arm64 的具名范围，不外推旧系统、Linux musl 或任意环境变化；Dev Container / Codespaces 不属于 live-runtime 正式支持范围。Windows Codex 节点内向上翻页限制保持。Restricted Mode 仅有限画布能力，Virtual Workspace 不支持。

桌面通知尽力投递；真实通知权限、点击回跳与市场自动补齐安装依赖仍取决于实际宿主。Fork 视觉边界、跨节点多指触控与真实 TUI resize 的既有人工复核边界保持。

## 验证范围

`npm run release:preflight -- --version 0.26.1` 检查版本与静态输入。`npm run release:verify -- --version 0.26.1` 执行标准完整门禁：门禁回归、完整 `npm test`、HEAD 的 clean-checkout VSIX 打包及安装 smoke。0.26.0 的一次性例外不适用于本版。发布准备 PR 使用最新 head 与基准分支生成的预合并结果，正式发布在最终 tag ref 再次验证，并使用匹配原生输入的六目标资产。

定向复核 root 身份与启动准备（`test:runtime-root-ownership`、`test:runtime-root-preparation`），并补充 Host/Supervisor 执行接线、reader 客户端、旧历史、请求超时与提醒桥接回归。notifier 执行 typecheck/source、companion 和英中文 locale smoke，检查独立 VSIX 的版本、本地化资源与双包安装关系。终端链接 helper 与 Agent/Terminal 的真实 xterm 折行、选区重绘回归也纳入验证。Marketplace 宿主 E2E、Webview 全套及 packaged smoke 都保留在完整门禁中。

已有三平台原生协调、已安装产品、多窗口/Remote 与真实 Agent Reload 的证据仅按 root 归属及运行时设计中的具名范围复用，不宣称本轮重新完成跨平台全矩阵。真实市场安装与桌面通知点击按发布手册在对应宿主复核；本地和 CI 的 staged smoke 不代证这些外部路径。
