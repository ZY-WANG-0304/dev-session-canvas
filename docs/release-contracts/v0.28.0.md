# v0.28.0 发布契约

## 发布范围

主扩展与 notifier 同步为 `0.28.0`，交付自 `0.27.0` 后已合入 main 的画布交互和文件活动退役更新。范围包括 `Agent`、`Terminal`、`Note` 与普通用户分组的标题编辑图标入口；聚焦执行终端对实际输入字符 `/` 的 `Ctrl+/` 映射；退役 Claude 文件活动采集、自动 `file` / `file-list` 节点、过滤设置和专属关系。

旧画布读取时清理扩展生成的文件活动记录、自动文件节点 / 边和失效分组成员；保留其他节点、普通连线、分组、会话身份和磁盘文件。终端文件链接、Markdown Note 文件关联、Explorer 创建执行节点和普通手工连线不在退役范围。notifier 不改变通知投递行为、协议、后端选择、点击回跳或本地化。发布工具与 CI 改造不是用户功能。

## 用户 release notes

标题文字现在保留选择、拖动或聚焦语义；在标题尾部出现的编辑按钮进入改名，workspace root 标题与只读投影仍不可编辑。执行终端在当前输入字符为 `/` 时，将聚焦 xterm 的 `Ctrl+/` 映射至 ASCII US（`0x1f`）输入，并保留 `Ctrl+C` 打断行为；真实 Codex CLI PTY 尚未验证，不将映射描述为真实 CLI 端到端验收。

自动文件活动和自动生成的文件 / 文件列表节点已退役。升级读取旧画布时，相应自动活动记录、节点、关联边和失效分组成员会被清理；迁移写回后该派生状态不保证可降级恢复。磁盘文件不删除；普通连线、终端文件链接、Markdown Note 文件关联及 Explorer 创建执行节点继续保留。主扩展与 notifier 同步 `0.28.0`，notifier 没有独立行为变化。

## 已知限制

真实 VS Code 中标题按钮的键盘焦点、高对比主题和宿主持久化人工验收不由 Webview 自动化覆盖替代。`Ctrl+/` 浏览器输入回归不代表真实 Codex CLI 将 `0x1f` 解释为 `/side`。文件活动迁移会删除旧扩展派生状态，不删除磁盘文件；跨版本回退及旧 Runtime 数据兼容仍受 Preview 既有限制。平台和运行时恢复支持边界不因本版扩大。

## 验证范围

发布 PR 的真实最新预合并 SHA 使用 `release-pr` 完整任务图及 `Verify release contract`；版本合并后的最终产品 SHA 再独立使用 `release-tag` 完整任务图生成固定双包批次。覆盖版本与文案静态检查、标题编辑指针 / 键盘与布局回归、执行终端 `Ctrl+/` 输入映射、文件活动旧画布迁移及保留数据 / 功能检查、notifier companion 与同批双包完整门禁。局部 PR 测试、本地 `acceptance: false` 或上版证据不替代本版正式跨平台验收。
